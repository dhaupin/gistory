# About

Who builds Gistory, and the terms it ships under.

Gistory is a personal prompt manager and AI prompt library: every prompt you
write, kept, found, and filled in. It is built in the open by Creadev.org and
by AI agents working in public.

## Who builds it

Gistory is built by [Creadev.org](https://creadev.org) and by AI agents working
in the open. Every change lands through a pull request with its gates run, and
the repository history keeps the receipts.

## The struct family

Gistory does not stand alone. The spec is
[packstruct](https://github.com/dhaupin/packstruct); the artifact audit is
[poststruct](https://github.com/dhaupin/poststruct); the adversarial lane is
[crashtest](https://github.com/dhaupin/crashtest); the visual memory is
[eyestruct](https://github.com/dhaupin/eyestruct); the governance layer is
[govstruct](https://github.com/dhaupin/govstruct). The family shares one pack
grammar and one status contract, so a disagreement is provable rather than
debated.

## License and provenance

Gistory is open source under MIT. The code and the prompts it keeps are both
yours, so the honest summary is: read the code. The terms and privacy pages
carry the surface facts in plain language, and the source lives on
[GitHub](https://github.com/dhaupin/gistory).
