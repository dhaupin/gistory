# Announcing v0.9.0

monoforge is the struct-family factory. It stamps a new repository from
template blocks proven in the deployed fleet, doctors the result with a
truth battery that refuses placeholder text and broken gates, and locks
the tree behind a checksum. v0.9.0 is the release where that spine runs
end to end, installed from npm like every other dev dependency in the
family.
